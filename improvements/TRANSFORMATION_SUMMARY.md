- ✅ 支持YAML配置文件
- ✅ 所有行为都可通过配置调整

**配置化内容:**
```yaml

# 处理参数

# 行为控制

use_dynamic_context: true

    semantic_boosting: true
  technology:
    semantic_boosting: false
```
