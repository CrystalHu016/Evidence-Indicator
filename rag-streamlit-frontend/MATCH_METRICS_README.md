# Character-Level Match Rate Evaluation Metrics

## 概要 (Overview)

このシステムは、抽出された根拠情報（Evidence）と元のデータセット回答の間の一致率を文字レベルで評価します。

This system evaluates the match rate between extracted evidence and original dataset answers at the character level.

## メトリクス (Metrics)

### 1. マッチ率 (Match Rate) - F1スコア
- **定義**: 精度と再現率の調和平均
- **範囲**: 0.0% ~ 100.0%
- **計算式**: `F1 = 2 × (Precision × Recall) / (Precision + Recall)`
- **意味**: 全体的な一致の質を表す総合指標

### 2. 精度 (Precision)
- **定義**: 抽出した根拠のうち、データセット回答と一致する割合
- **範囲**: 0.0% ~ 100.0%
- **計算式**: `Precision = 重複文字数 / 抽出した根拠の文字数`
- **意味**: 抽出した情報の正確さ（余分な情報が少ない）

### 3. 再現率 (Recall)
- **定義**: データセット回答のうち、根拠に含まれている割合
- **範囲**: 0.0% ~ 100.0%
- **計算式**: `Recall = 重複文字数 / データセット回答の文字数`
- **意味**: 答えをどれだけカバーしているか（情報の漏れが少ない）

### 4. 完全一致 (Exact Match)
- **定義**: 根拠とデータセット回答が100%一致するか
- **値**: ✅ はい / ❌ いいえ
- **意味**: 完璧な抽出ができたか

## 使用例 (Examples)

### Example 1: 完全一致
```
根拠: "古今集"
データセット回答: "古今集"

結果:
- マッチ率: 100.0%
- 精度: 100.0%
- 再現率: 100.0%
- 完全一致: ✅ はい
```

### Example 2: 部分一致（答えが根拠に含まれる）
```
根拠: "『古今集』の成立は『万葉集』よりも時代が下る"
データセット回答: "古今集"

結果:
- マッチ率: 24.0%
- 精度: 13.6% (3文字一致 / 22文字)
- 再現率: 100.0% (3文字一致 / 3文字)
- 完全一致: ❌ いいえ

解説: 答えは完全に含まれているが、余分な情報が多いため精度が低い
```

### Example 3: 不一致
```
根拠: "万葉集"
データセット回答: "古今集"

結果:
- マッチ率: 33.3%
- 精度: 33.3% (1文字一致「集」/ 3文字)
- 再現率: 33.3% (1文字一致「集」/ 3文字)
- 完全一致: ❌ いいえ

解説: 「集」という1文字だけが共通
```

## 評価の解釈 (Interpretation)

### 高品質な抽出 (High Quality)
- **マッチ率 > 80%**: 非常に良い抽出
- **精度 > 90%**: 余分な情報が少ない
- **再現率 > 90%**: 答えをよくカバーしている

### 中程度の品質 (Medium Quality)
- **マッチ率 50-80%**: まあまあの抽出
- **精度が高く再現率が低い**: 答えの一部だけを抽出
- **精度が低く再現率が高い**: 答えを含むが余分な情報が多い

### 低品質な抽出 (Low Quality)
- **マッチ率 < 50%**: 改善が必要
- **両方とも低い**: 答えと異なる情報を抽出

## 利点 (Benefits)

1. **定量的評価**: 主観的でなく数値で評価可能
2. **詳細な分析**: 精度と再現率で問題の種類を特定
3. **自動化**: 人手を介さず自動で計算
4. **リアルタイム**: クエリ実行時に即座に表示
5. **履歴追跡**: 過去のクエリも評価可能

## 制限事項 (Limitations)

1. **文字レベル評価**: 意味的な正しさは評価しない
2. **順序依存**: LCSは文字の順序を考慮
3. **言語依存**: 日本語に特化（他言語は調整が必要）
